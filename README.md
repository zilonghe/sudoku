# 数独 Sudoku

精美移动端优先的数独网页游戏，支持离线游玩。

**在线地址：** https://zilonghe.github.io/sudoku/

## 功能

- 四种难度：入门 / 中等 / 困难 / 大师（唯一解生成）
- 计时器、暂停、通关用时
- 错误计数（大师模式关闭纠错）
- 笔记模式、撤销、提示、清除
- 同数高亮、冲突高亮
- localStorage 自动保存进度
- 深色 / 浅色自适应

## 本地预览

用任意静态服务器打开本目录即可，例如：

```bash
python3 -m http.server 8080
```

然后访问 http://localhost:8080
